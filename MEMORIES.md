## ⛔ HARD WRITING RULE — NO MID-SENTENCE COLONS (do not violate, ever)

Uriah has flagged this 4-5 times and is rightly fed up. **Never use a colon mid-sentence** before a single explanatory word, clause, or example, in ANYTHING — SOQ, STD 678, resume, cover letter, AND chat messages to him. A colon may ONLY introduce a real list or formatted series. If you are about to write "X: Y" where Y explains or expands X, STOP and rewrite with a period or comma. Example of the violation he hates: "I administer Active Directory directly: creating users and groups." Fix: "I administer Active Directory directly. I create users and groups." Before sending any draft or message, scan every colon and confirm each one introduces a list, not an explanation. This is a zero-tolerance item.

**SOQ is stricter still (settled 2026-06-21): an SOQ contains ZERO colons of any kind**, not even a list-introducing one, because SOQ answers flow as one paragraph with no formatted lists for a colon to introduce. The only exception is a true numeric colon (a clock time like 7:00, a ratio like 3:1). This does NOT extend to the resume, which keeps its label-colons (skills rows, project headers), or to the STD 678. The `tools/verify_doc.py` pre-submit gate enforces the SOQ zero-colon rule and no longer runs the colon check on resumes. One known edge: if a posting's SOQ question text itself contains a colon and you restate the question verbatim (required), the gate will flag that colon. That is an expected false positive on the agency's own wording. Keep the verbatim question and override the flag.
